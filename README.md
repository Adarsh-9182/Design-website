# Design Website

An original, responsive landing page for a fictional independent creative studio. The visual direction uses an editorial type system and CSS-built artwork in a citrus, mint, and ink palette—no copied imagery or brand assets.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
```
